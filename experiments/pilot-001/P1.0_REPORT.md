## 4. 由此得到的任务设计要求（写给 P1.2）

要区分 C−A / B−C，任务必须满足：**失败信息只能通过执行或独立验证获得**，代码静态可见的信息不足以修复。

候选（下一步实现）：
- **T-C v1（执行可见）**：契约能通过，但仿真执行因目标不可达/碰撞失败；C 可从 telemetry 看到错误，A 不能。
- **T-B v1（组合）**：需要两段链的执行结果才能发现第二段后置条件不满足；只有 B 能看到结构化后置条件判定。
