# 待填字段清单（5 分钟填完即可出正式包）

> 复制下面 JSON，把尖括号内容替换成真实信息，另存为 `team.json`，然后：
> `python3 make_release.py --team team.json`

```json
{
  "school": "<学校全称，如：郑州信息工程职业学院>",
  "category": "<研究生 | 本科生 | 高职高专生>",
  "team_id": "<报名系统分配的队伍编号>",
  "project": "AgenticFlex",
  "members": ["<队长姓名>", "<成员姓名>", "<成员姓名>"],
  "advisors": ["<指导教师1>", "<指导教师2>"]
}
```

## 逐项说明
| 字段 | 说明 | 约束 |
| --- | --- | --- |
| school | 学校全称（与报名一致） | 以校为单位，严禁跨校 |
| category | 学生类别 | 三选一：研究生/本科生/高职高专生 |
| team_id | 队伍编号 | 报名成功后系统给 |
| project | 项目名称 | 默认 AgenticFlex，可改 |
| members | 学生成员 | 1–3 人（含队长）；队长放第一个 |
| advisors | 指导教师 | ≤2 人 |
