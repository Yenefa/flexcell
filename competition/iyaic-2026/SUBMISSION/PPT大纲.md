# 展示 PPT 大纲（≤ 8 分钟答辩）

1. **封面**：项目名 + 创意组 + 学校 + 队伍编号
2. **一句话价值**：让机器人"听懂任务、自己决策、可被验证"。
3. **痛点**：机器人编程门槛高、脚本脆弱、过程不可审计、仿真到真机难复现。
4. **方案总览**：Agentic 柔性工作单元（自然语言 → 决策层 → 技能层 → 执行 → 独立验证）。
5. **技术架构图**：决策（FSM/Jev/LLM/Hybrid 可降级）/ 技能（observe·pick·place·verify + MoveIt2/MTC）/ 执行（ros2_control/Gazebo）/ 验证与安全门。
6. **创新点 1**：可调用的"技能契约" + 策略路由（不 deadlock、可降级）。
7. **创新点 2**：证据化交付——决策日志/episode/帧 + 独立验证 + 落点误差。
8. **创新点 3**：可信仿真-真机一致 + 数据闭环（rosbag 对账修复实时丢帧）。
9. **创新点 4**：迁移成本可度量（TransferBench：参数/对象/组合/恢复/平台）。
10. **演示**：核心 5 任务窗口 `FUNCTIONAL_WINDOW_PASS` + 视觉选物（2.5 mm）+ composite 单链成功。
11. **应用与市场**：高校/职教实训、实验室自动化、小件柔性装配；社会价值=降低门槛+可复现教学。
12. **团队与计划**：分工、里程碑、路线（真机标定 / 通用感知 / 多臂）。
