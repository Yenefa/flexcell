# 一键提交（拿到队伍信息后照做）

## 0. 填信息
把 `team.json` 填好（格式见 `待填字段清单.md` / `team.example.json`）。

## 1. 生成正式包
```bash
python3 make_release.py --team team.json --out build
```
预期输出：`remaining <placeholders> in plan: 0` → 一致性 PASS → 评分 PASS → `ZIP: build/创意组+河南+<学校>+<项目>+<类别>+<编号>.zip`（16 文件）。

## 2. 就绪复核
```bash
python3 build/readiness_check.py
```
预期：`READY_TO_SUBMIT`。

## 3. 记录指纹（回执用）
```bash
sha256sum build/*.zip
```
把 sha256 / 文件大小 / 生成时间填入 `发送回执模板.md`。

## 4. 发邮件
- 打开 `邮件提交正文.md`，按模板填主题/正文；
- 附件 = 第 1 步的 zip（**不要改名**，与主题一致）；
- 收件人 **iyaicmsczh@163.com**；建议抄送队长邮箱。

## 5. 归档回执
- 发送成功截图（含时间、收件人、附件名）存 `evidence/`；
- 填完 `发送回执模板.md` 并归档。
