# 答辩现场操作卡（一键复跑 / 预期输出 / 兜底）

> 环境：WSL2 Ubuntu 24.04；启动前先清残留进程。

## 0. 准备
```bash
pkill -9 -f "gz sim"; pkill -9 -f move_group; pkill -9 -f task_fsm_server; sleep 3
source /opt/ros/jazzy/setup.bash
source ~/agentic_workcell_ws/install/setup.bash   # 上游 open_manipulator
source ~/flexcell-ws/install/setup.bash            # 本项目
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp ROS_DOMAIN_ID=45 LIBGL_ALWAYS_SOFTWARE=1
```

## 1. 核心 5 任务窗口（主演示）
```bash
python3 scripts/sim_window.py --manifest infra/core-window.json --out /tmp/win \
  --backend velocity_servo --skill-backend legacy
```
**预期**：`"status": "FUNCTIONAL_WINDOW_PASS"`，5 个 trial 全 expectation_met（最后一个是 EXPECTED_FAILURE）。
**失败兜底**：切到已录 demo（`SUBMISSION/evidence/demo_sim.mp4`）+ 台账 `EVIDENCE.md`，如实说明环境波动。

## 2. 相机路径（视觉展示）
```bash
python3 scripts/sim_smoke.py --out /tmp/cam --backend velocity_servo \
  --case normal --object target_box_a --camera
```
**预期**：`"status": "PASS"`，`reconcile.status="RECONCILED"`，`backfilled>0`；`/tmp/cam/run-*/data/images/*.png` 有帧。

## 3. 多任务链（可选，展示 composite）
```bash
python3 src/flexcell/flexcell_skills/test/composite_probe.py --object target_box_a --place 0.12 -0.15 0.0175
```
**预期**：`"outcome": "OUTCOME_SUCCEEDED"`，`completed_stage_ids:["one"]`。

## 4. 常见故障
- `move_group` 段错误 / `joint_state_broadcaster` 配置失败 → 多半是上一轮 gz/ros 残留，回到第 0 步清理重来。
- `/run_composite` 无 server → 未 source 本项目 install，或 install 与源码不一致（重建）。
- `installed/source identity mismatch` → 源码改过未重建，`colcon build` 再跑。

## 5. 口径
- 只报已跑通事实：n=1 功能窗口，不称成功率；n≥50 未放开。
