## 一、项目题目
**AgenticFlex：面向教育与柔性装配的智能体驱动机器人工作单元**

## 二、项目摘要
本项目构建一个"智能体（agent）驱动机器人"的柔性工作单元：用户用自然语言下达任务，系统经由**分层决策**
（决策层→技能层→执行层→独立验证层）把任务拆解为可安全执行的技能动作（观察、抓取、放置、验证），
在仿真与真机上均可运行，并把每一步决策、观测与结果**证据化留存**、可离线复现。相比传统硬编码脚本，
它把"机器人怎么做事"与"要做什么"解耦：agent 负责意图，工作单元负责安全、可验证地执行。

## 三、项目背景与国内外研究现状
- 背景：AI 大模型与机器人结合成为热点，但"会聊天"到"能安全干活"之间缺少可靠的运行时契约与验证。
- 现状：Isaac/ROS-MCP 等生态提供工具与开发平面；工业机械臂编程仍依赖专家脚本；教学实训缺少"可复现、可审计"的一体化平台。
- 机会：把"agent 技能调用 + 分层安全执行 + 数据闭环"做进一个可教学、可研究、可迁移的工作单元。

## 四、研究内容与技术路线
1. **决策层**：WorldState v2 + DecisionPolicy 接口；内置 FSMPolicy 参考实现，可切换 Jev/LLM/Hybrid，失败时**降级不 deadlock**。
2. **技能层**：observe / pick / place / verify 四类技能，统一失败语言；运动规划经 MoveIt 2 / MTC 走同一执行器。
3. **执行层**：ROS 2 Jazzy + ros2_control + Gazebo Harmonic（可信仿真）；同一套 launch 可切真机。
4. **验证层**：独立 Verify 技能 + 安全门（目标/可达/碰撞/预算），拒绝越界提案。
5. **数据闭环**：LeRobot 标准记录 + rosbag 对账回填（解决实时丢帧），导出前门禁校验采样间隔。
6. **迁移成本基准（TransferBench）**：按参数/对象/组合/恢复/平台五轴度量"从冻结起点到新任务"的工程成本。

## 五、创新点
1. **技能契约 + 策略路由**：agent 只调用声明式技能；决策策略可插拔并在异常时降级，兼顾灵活与安全。
2. **证据化、可验证**：每步 decisions/episode/帧与独立验证结果留痕，支持离线策略输入回放，教学与科研可审计。
3. **可信仿真-真机一致 + 数据闭环**：可复现的 profile 与 rosbag 对账，使"仿真验证过的行为"可解释地迁移到真机。
4. **迁移成本可度量**：TransferBench 让"加一个新任务要花多少工程投入"第一次被量化。

## 六、应用前景与社会价值
- 市场：高校/职教机器人与 AI 实训平台、实验室自动化、小件柔性装配与分拣。
- 社会价值：用自然语言降低机器人使用门槛，让非专家也能安全驱动机器人；证据化让教学可复现、科研可比较。

## 七、存在的问题与改进方向
- 感知目前偏约束（颜色选择 + AprilTag 只读定位）→ 计划引入通用目标检测与位姿估计。
- 真机需硬件标定与安全认证 → 计划建立从仿真到真机的标定与安全规程。
- 成功率统计尚冻结（n≥50 未放开）→ 计划在受控窗口内做统计化评估。
- 单臂为主 → 计划扩展双臂协同与多工位。
