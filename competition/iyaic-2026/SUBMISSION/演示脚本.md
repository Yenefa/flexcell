# 演示脚本（现场答辩 / 录屏）

## A. 现场可复跑（推荐，最真实）
1. 环境：WSL2 Ubuntu 24.04 原生 ROS/Gazebo（ldvmpipe）。启动栈等 health=IDLE、reset。
2. 跑 `scripts/sim_window.py --manifest infra/core-window.json`，展示 **5/5 expectation 达成**。
3. 跑 `scripts/sim_smoke.py ... --camera` 展示视觉帧 + 落点误差 + 对账回填。
4. （可选）跑 `test/composite_probe.py` 展示"多任务链"能力（`OUTCOME_SUCCEEDED`）。

## B. 录屏分镜（≤3 分钟）
1. **0:00–0:20** 一句价值 + 痛点。
2. **0:20–0:50** 架构图（决策→技能→执行→验证）。
3. **0:50–2:10** 现场跑核心窗口：字幕标注 A/B 落点误差、dual、recovery、budget 期望失败。
4. **2:10–2:40** 相机路径：画面帧 + reconcile 回填数字。
5. **2:40–3:00** 证据收尾：指纹、CI 绿、离线测试数。

## C. 兜底
- 若现场环境不稳：用本台账 `evidence/EVIDENCE.md` 的已跑结果 + 预先录屏，绝不现场伪造。
- 任何"没跑通"就如实说明，不宣称成功率。
