## 2. 关键归因（W5-E2）
- 三次失败都不是"改错值"，而是**没有写操作**；
- transcript 证明 agent 已算对：`zone_2 at (0.45,0.05) has reach ≈ 0.4528 m — out of reach`；
- 真正瓶颈：**探索预算**（4 轮内完成"探索 + 定位 + 写入 + 验证"不够）与目录读取报错（已修）；
- E2b 通过"6 轮 + 明确 gate 只读"解决；这是**协议重注册**，不是对 E2 的事后修改。

## 3. 过程中修复的 harness 缺陷（非实验证据）
1. `gate/sim.py` 未加工作区根到 `sys.path`（W5-E1）；
2. 允许动作集未在技能文档声明（E1）；
3. Windows 侧无 pytest → 无依赖回归运行器；
4. W5A 工具集继承 A 臂（缺 `run_execution`）；
5. `_wsl` 未转换 `C:\` → `/mnt/c/`；
6. `--config-override` 平台杠杆缺失；
7. `read_file` 读目录抛 `PermissionError` → 目录可读 + `list_dir`；
8. `edit_file` 工具（单次匹配）+ 迭代进度提示；
9. 缺陷注入误改旧键 `zone_zone_2_x` → 最小覆盖文件。

## 3b. 行动缺口（跨样本）
见 `docs/W5_ACTION_GAP_ANALYSIS.md`：8/8 失败样本零写操作；E2c（旧提示）0/2、阅读 31 次；E2d（显式行动指令）2/2、首写前读取 2 次。
方向支持"探索胃口"假设，但 n 小、单模型，不能外推。

## 4. 限制
- 合成层与真实层均 **n=1/3**，单任务、单模型（deepseek-chat）；
- 缺陷是**人工注入**的受控实验，不是自发发现；
- 回归门只覆盖一个既有场景（normal），不是完整回归套件；
- **M3-R（真机）未达**；
- W5-E2 与 E2b 协议不同，不能合并统计。
