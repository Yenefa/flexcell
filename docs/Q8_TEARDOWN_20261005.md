# Gazebo pose worker shutdown repair — 2026-10-05

## Reproduced failure

The Q8 pilots retained under `q8_pilot_20261005` stopped on a real admin/reset
cleanup failure: the isolated pose worker exited with SIGABRT (-6). Their
truncated denominators remain frozen. This repair does not replace those runs.

An uninstrumented production subscriber lifecycle probe reproduced the abort
on attempt 26; a second probe reproduced it on attempt 3 with core dumps enabled.
The captured core is from Python 3.12 with Gazebo Transport 13.6.0. Its stack
shows the Python main thread in `Py_FinalizeEx`, while the transport reception
thread destroys `RawSubscriptionHandler`, enters `PyEval_AcquireThread`, calls
`PyThread_exit_thread`, and reaches `std::terminate`/SIGABRT during forced unwind.

This identifies the shutdown race: an in-flight native handler still owns a
Python callback when interpreter finalization begins. `unsubscribe()` returning
does not prove that callback references have all been destroyed. The matching
[Transport 13.6.0 reception code](https://github.com/gazebosim/gz-transport/blob/gz-transport13_13.6.0/src/NodeShared.cc#L403)
copies handler references under a mutex, then invokes callbacks outside it; the
[Python binding](https://github.com/gazebosim/gz-transport/blob/gz-transport13_13.6.0/python/src/transport/_gz_transport_pybind11.cc#L263)
captures the Python callable in its native callback.

## Minimal repair

After subscribing, the worker gives transport the only strong reference to its
Python callback. A `weakref.finalize` event observes the callback's actual final
release. On shutdown the worker checks unsubscribe success and waits up to
three seconds for that event before allowing normal interpreter finalization.
It releases the GIL while waiting so native callback destructors can finish.

Unsubscribe failure or release timeout remains an error. The admin process still
rejects abnormal worker exits; SIGABRT is not an accepted teardown code.
`stop_gz_pose_stream` now includes the captured native stderr in its exception
so a recurrence is directly diagnosable.
