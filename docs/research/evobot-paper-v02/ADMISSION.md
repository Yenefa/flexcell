# ADMISSION — 准入清单（v0.1 草案）

> **状态：DRAFT v0.1。全部条目当前为「未满足」。**
> 本清单没有任何一项已被签字。它描述的是「#252 开工前必须补齐什么」，
> 而不是「已经补齐了什么」。准入未通过 → 24 个槽位保持 `NOT_RUN`。

## 1. 准入总则

| # | 规则 |
| --- | --- |
| R1 | 准入项**全部**满足后，才能把任何槽位从 `NOT_RUN` 改为 `RUNNING`。 |
| R2 | 准入签字一旦生效，本协议从 `DRAFT` 升为 `FROZEN v0.1`；之后改任一参数即升版本（[PROTOCOL.md](PROTOCOL.md) §8.3）。 |
| R3 | 准入阶段**不得**同时跑实验；准入验证（`ADMISSION_CHECK`）不进任何分母（[DATA_DICTIONARY.md](DATA_DICTIONARY.md) §2）。 |
| R4 | 准入记录本身要能离线复核：每条附可执行命令 + 原始输出摘要 + 摘要 sha256。 |
