# Joint 跟随验证：预声明

本声明随实现提交，先于本窗口执行。执行后结果独立归档；不得修改声明、覆盖原始
记录或以补跑替换失败。这个窗口不改变 [D3 的 NO_GO 决定](DETACHABLE_ADMISSION_20261027.md)。

[`infra/joint-follow-window.json`](../infra/joint-follow-window.json) 固定 A、B 各一次，
最多两次逻辑任务；A 有任意未知状态、非预期结果或证据缺失则停止，不派发 B。
backend 固定 `detachable_joint`，skill 固定 `mtc`，不启用模型或硬件。每轮独立冷启，
运行时身份、world 和配置摘要须一致；第二轮在派发之前再次核对第一轮的指纹。

生成 world 的 SHA256 固定为
`cbfa8ad2f75f453aeca9498bb11a004d34ab987d95c62f00887c3eeaa39f40d4`；
去除输出路径后的语义配置 SHA256 固定为
`8077f2dc08e61d07558ccbab2a041d9ef6351f3021f0b87aae3f90f9443eeaee`。
启动后实测 2 ms 步长和最近 0.5 仿真秒的 RTF ≥0.3；不满足则不派发任务。

Pick 抬升后保持 11 个**仿真秒**，由仿真时钟确认且 wall time 限 60 秒。要求从首次
确认附着采样到释放前，完整覆盖至少 10 仿真秒：相对位置漂移严格 <2 mm、旋转
漂移严格 <1°。物理追踪器保留每个 2 ms 仿真步的原始 parent/A/B SE(3) 和实际
joint component，50 Hz 流与逐步原始记录逐点对齐；不裁掉任何附着帧。每步姿态必须
有限，连续位置跳变 <1 m；时间、帧数及 session ID 不完整一律拒收。

同时记录同一轮 RGB 图像、时间戳、机器人状态和数值动作。沿用 100 ms 相机采样与
对齐质量门禁；缺帧或缺图时停止窗口，不以选取好的帧替代。图像是未完成标定的数据
记录，不能代表视觉 Observe 或真实机械臂。此处不是 #58 指定的 S2 主机联调。

运行前检查源码、Python import、构建产物与 Git 提交身份；不启用旧部署 overlay。
两个试次必须使用同一语义指纹。每轮只允许完成一次任务，拒收时不自动重试。

运行时以首次同步观察到的附着相对变换为参照，以 50 Hz 检测跟随；如果数据中断、
组件消失或超过上述阈值，则要求取消当前运动，保留携带状态，并停止自动恢复。
控制器是否真正停稳以独立 motion result 为准；未知终态不允许自动复位。unit/integration
负例对假 attached、不跟随、超限、缺失、时钟、会话、未确认停稳进行测试；这些负例
尚不是整机实际故障注入试验。

边界：本次没有测接触力，也没有在无接触预定位时捕获 #57 要求的参考 SE(3)，没有
完成整机自由落体、S2 同轮画面联调或 legacy teleport/joint 矩阵。500 Hz 是仿真步频，
不是实时时钟上的吞吐承诺。即便 A/B 均通过，也不能直接签 D3 GO、证明接触抓持或
报告成功率。模型大样本继续冻结。
