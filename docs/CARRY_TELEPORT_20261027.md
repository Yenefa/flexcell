# Teleport carry 连续轨迹：振荡证据与未确认的机制

PR #69 的原始数据和 [对账文本](../setup/acceptance/local_run_20261027/RECONCILE.md)
逐字保留。以下为 2026-10-28 整合核查后的解释。

A1、A1b、A4 共六次 PICK，五次通过、一次 error 23，不是失败率估计。
六次 rise 约为 +0.0764、+0.0623、+0.0737、−0.0083、+0.0629、+0.0811 m。
失败的箱高端点为 0.0174999975 与 0.0091558874 m。

三份位姿流的选定保持段都有约 0.1003–0.1009 s 的垂直振荡；[观测器](CARRY_WATCH.md)
报告平均单周期峰峰约 67.6–70.6 mm。该指标不同于整个窗口的最大值减最小值。
原始全文件箱高约 0.0090–0.1254 m，不同窗口峰值不同。

这些记录支持本配置没有持续保持固定垂直偏移，并提示单次 rise 可能依赖采样时刻。
周期与 pin 周期相符是机制线索，不能单独证明自由落体是唯一原因。

Gazebo 位姿流未与 ROS action、pin 请求、最终测量做统一时钟联结。因此不能断言
失败采样恰好落在某个波谷，更不能把全部历史成功率归因于采样相位。旧确定性表述撤回。
夹爪高度减 0.16 m 只是近似参照，不是同步的实际 pin 目标；原对账已发现约 15 mm
系统偏差，不能把相对于该近似的偏差写成精确 pin 误差。

原报告的 demo 时长 27.79 s、zone 误差 0.0094/0.0050 m 和 action evidence ID
缺少机器生成的 result 落盘，无法验证，不作为端到端验收证据；不得补造缺失结果。
原始健康结果和位姿流仍保留。
