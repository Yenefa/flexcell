## 2. 检查表

### 2.1 硬件急停（E-Stop）
- [ ] 物理急停按钮存在且可达（**NOT_VERIFIED**：无硬件）
- [ ] 急停切断动力而非仅发软件停止（**NOT_VERIFIED**）
- [ ] 急停复位需人工确认（**NOT_VERIFIED**）
- **软件侧要求（已实现）**：任何未确认停止 → 进入 QUARANTINED，禁止新运动派发。

### 2.2 驱动器安全停止
- [ ] 驱动器支持 STO（Safe Torque Off）（**NOT_VERIFIED**）
- [ ] 停止类别符合 ISO 13849 / IEC 60204-1（**NOT_VERIFIED**）
- **软件侧要求（已实现）**：取消请求 ≠ 停止成功；必须等待终端结果且非 STATE_UNKNOWN。

### 2.3 安全 PLC / 等效保护
- [ ] 存在安全 PLC 或安全继电器（**NOT_VERIFIED**）
- [ ] 与 ROS 侧仅有单向状态读取，不被软件绕过（**NOT_VERIFIED**）

### 2.4 机械臂运动限位
- [x] 软件侧工作空间限制（`max_reach_m=0.30`，越界由安全门拒绝）——**仿真已验证**
- [ ] 硬件限位开关 / 机械硬限位（**NOT_VERIFIED**）
- [ ] 关节速度与加速度上限在真机上标定（**NOT_VERIFIED**）

### 2.5 动态障碍物检测
- [ ] 真实感知（相机/AprilTag）闭环（**NOT_VERIFIED**：当前仅 Gazebo ground truth）
- [ ] 人类接近时的降速/停止策略（**NOT_VERIFIED**）

### 2.6 夹爪机械安全
- [ ] 最大夹持力限制（`max_effort`）在真机标定（**NOT_VERIFIED**）
- [ ] 夹持失败检测（stalled / 无物体）——**软件侧已有 GripperCommand 结果消费，待 P1-D 完善**
- [ ] 断电时物体不坠落（**NOT_VERIFIED**）

### 2.7 控制器取消与制动行为
- [x] 软件取消链路：Action cancel → ros2_control 控制器停止（**仿真已验证**，约 50 ms）
- [ ] 真机制动曲线与停止距离（**NOT_VERIFIED**）

### 2.8 真机停止距离与减速度
- [ ] 在最不利速度/负载下的停止距离测量（**NOT_VERIFIED**）
- [ ] 与工作空间边界的安全余量计算（**NOT_VERIFIED**）

## 3. 进入真机测试的前置条件（硬性）
1. 2.1–2.3 全部 PASS 并留存证据（照片/型号/证书）；
2. 2.4–2.8 逐项测量并写入本文件；
3. P0-A 的隔离逻辑在真机上复测（未确认停止 → 隔离 → 人工复位）；
4. 低速、空载、限幅的首次上电流程；
5. 独立人员在场，急停可达。

## 4. 与软件的关系
P0-A 保证的是"**软件不会在状态未知时继续发运动指令**"，这是真机安全的**必要非充分**条件。
硬件安全链缺失时，软件隔离只能降低风险，不能替代急停与 STO。
