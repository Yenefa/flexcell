## 2. 可证伪命题

**H1**：在**受约束接近**场景中（目标上方有低矮顶板，只允许近乎垂直的进入角），
MTC 后端（`--skill-backend mtc`）能完成任务，而 legacy/FSM 后端**失败**。

**H0（零假设）**：两个后端**要么都成功、要么都失败**——即 MTC 在该场景类中
**不展示** FSM 缺失的能力。

**判据（运行前固定）**：
- 若 `mtc` PASS 且 `legacy` FAIL → **支持 H1**；
- 若两者结果相同 → **H0 成立**，记录为负结果；
- 若 `mtc` 也 FAIL 但失败原因不同（如规划超时 vs 碰撞）→ **不可判定**，需更大对比，不为凑结论重复跑。

## 3. 场景

在生成的 `world.sdf` 中为目标 `target_box_a` 上方加入一块**静态顶板**（薄 box），
使机械臂无法从正上方以自由姿态进入，只能用更受限的接近轨迹。

对象、分区、验收器、判定阈值**全部不变**；只增加静态几何。
