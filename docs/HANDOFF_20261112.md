## 6. 已确认的坑

| 坑 | 症状 | 做法 |
| --- | --- | --- |
| **WSL 里 git** | `.git` 是 pointer file，报错输出像「0 行差异」 | **git 一律 Windows 侧** |
| 猜 ROS 字段 | 本会话 6 次，每次烧 5 分钟仿真 | 先跑 `benchmark/tools/check_ros_interfaces.py --describe` |
| `pkill -f "[$n]"` | `[carry_server]` 是字符类，实测误杀 4/4 | 用 `[c]arry_server` |
| 孤儿进程 | 136 个泄漏让 A-v0 71/72 掉到 44/72 | 批次后查残留，别在 gz=0 时判「干净」 |
| `sample_gz_pose` | 第一参数是**模型名**不是 node | `sample_gz_pose("target_box_a")` |
| `CompositeStage.place_pose` | 是 **PoseStamped**，需 `frame_id='world'` + 四元数精确 `[0,0,0,1]` | 见 preflight |
| `plan.json` | **已是 RunComposite 格式** | 读 `task_id` / `stages[].place_pose` |
| 运动档 | 计划自带 `demo_slow` | 别硬编码 `legacy` |
| `sed -i` 在 `/mnt/c` | 权限失败，变异没生效却以为生效 | 用 Python 改，改完比哈希 |
| `no tests ran` | 曾被读成「通过」 | 必须有 `N passed` |
| T08 判 `passed=False` | 常因**缺轨迹** | 看 `terminal_passed` 与 `failure_reason` |
| `displacement_m` | **无符号模**，反向也算进展 | 用 `displacement_along_direction_m` |
