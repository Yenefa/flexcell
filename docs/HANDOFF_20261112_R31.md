## 4. The infrastructure lesson, so it is not repeated

**ROS 2 domain IDs are valid only 0–232.** Above that, node creation fails with
`RCLError: error creating node: error not set` at `rcl/node.c:252`. Rounds 21–25 were lost to this: a wrapper
was written using domains 241–246, the resulting failures were diagnosed as a dead simulator for two rounds,
and the cause was the domain choice. **`ROS_DOMAIN_ID=183` was valid all along.**

Check list before any Gazebo batch: (1) domain in 0–232; (2) one isolated trial reaches `push_object`;
(3) `/dev/shm` free; (4) no stray `gz sim`.
