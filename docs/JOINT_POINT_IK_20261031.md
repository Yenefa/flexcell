## 修复内容

在规划器私有模型中，从原始 URDF/SRDF 增加一个无碰撞几何的固定 TCP 点和 arm
别名，让 position-only KDL 直接求解附着箱体中心。保留原始四个主动关节、规划
关节限制、碰撞矩阵和附着几何；夹爪和控制器模型不变。释放后的 EE 竖直退避继续
使用原 `arm` 组，技能层继续独占执行权。

增加可选的规划留证：保存实际 request、完整 GetPlanningScene reply 和 response
的 CDR 原始字节，以及原始 URDF/SRDF。写证失败返回规划失败并清空轨迹。
新声明 `infra/joint-point-ik-local.json` 保持原来的世界、参数和物理门槛。
