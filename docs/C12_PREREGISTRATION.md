# C12 预注册 — MTC 是否具备 FSM 缺失的能力？（机制检验，非样本扩张）

> C3–C11 只比较同一抓放任务的成败/耗时；C12 直接问**能力差异**。
> 假说：MTC 的价值在"约束下可行轨迹规划"，FSM 的固定笛卡尔路径在
> **需要绕行/多候选**的场景应失败或退化，而 MTC 应能通过。

## 1. 场景（无需新世界，用既有 case + 参数）
| 编号 | 场景 | 构造 | 预期区分 |
| --- | --- | --- | --- |
| A | 基线 dual_object | 默认 | 两臂都应 PASS（对照） |
| B | 目标区被物体占据 | `dual_object` + 把 zone_2 设到 zone_1 附近（<2×半径） | FSM 直落冲突；MTC 若有避障/规划应仍能放置或明确失败 |
| C | 需跨对象绕行 | `regrasp` + `zone-2-pose` 使第二段路径穿过第一对象上方 | 轨迹可行性差异 |

## 2. 指标
- 状态（PASS / ROBOT_FAILURE + error_code）、wall、`fsm_trace`；
- MTC 侧额外：`planner_diagnostics`（如可用）、`mtc_stages` 审计条目数；
- **能力判据**：至少一个场景下 FSM 失败而 MTC 成功，且失败原因是"无可行路径/碰撞"类，而非规划超时。

## 3. 判读（冻结）
- 出现"FSM 失败 / MTC 成功（非超时）" → 记 **MTC 具备该能力差异（单场景证据）**；
- 两臂同败或 MTC 因超时失败 → 记 **负结果**：本轮未找到 MTC 的能力优势；
- 不扩大普通场景样本；每场景每臂 ≤3 次；
- 不修改验收器/阈值/世界。

## 4. 预算
- 场景 A/B/C × 2 臂 × 2 次 = 12 次真实 Gazebo（约 10–12 分钟）；
- 单次超时 600 s；一次高负载仿真。
