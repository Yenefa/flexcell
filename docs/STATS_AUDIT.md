# 统计口径审计（2026-11-09）

> 目的：统一全仓统计数字与检验方法，纠正已发现的错误。所有数字可由对应证据文件重算。

## 1. 方法
- 两臂成功/失败用 **Fisher 精确检验（双侧）**；
- 不把 n<10 的差异写成"显著"；p 值只作描述；
- 每个数字必须指向 `setup/acceptance/**` 或 `experiments/pilot-001/runs/**`。
