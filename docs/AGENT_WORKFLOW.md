# 云端开发与家用 GPU Agent 的分工

用户确认的执行机是家里的 **AMD Radeon RX 6800**。此前提及的 NVIDIA 4060 Ti 不作为当前测试目标。

云端 Agent 负责修改代码、执行可用的 CPU 检查、提交待审核 PR，并为需要 GPU 的任务提供可直接转发的提示词。用户把提示词转给家用电脑上的 Agent，后者在本机运行、收集报告，再由用户把报告带回云端。云端据报告修复并准备下一轮任务。

日常交接默认复用用户已跑通的环境、服务、缓存和测试证据，只下发当前代码仍缺的测试。相同脚本、输入与参数已有合格报告时直接回传，不重复环境探测或部署；仅在环境变化或实际错误需要诊断时追加针对性检查。

每次交接包含任务编号、确定的 Git 提交、输入/模型版本、执行步骤、通过条件、结果回传格式。电脑 Agent 回传实际执行命令、提交 SHA、硬件和后端、完整 JSON 报告与错误日志。若自行调整依赖或代码，同时回传版本清单和 diff。

CPU 检查、GPU 环境探测、GPU 模型推理、Gazebo 闭环和真实硬件实验分别记录。通过前一项不能代替后一项。没有电脑 Agent 的实际 GPU 报告时，GPU 状态保持待验证。

该工作流通过用户转交任务和结果，不依赖云端直接接入 Tailscale，也不需要为云端另开远程控制入口。

首个任务见 [RX 6800 推理验证提示词](../setup/learned_policy_validation/GPU_AGENT_TASK.md)。
