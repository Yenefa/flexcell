# 云端开发与本机测试分工

云端 Agent 负责写代码、准备测试入口、执行可用的云端检查和提交待审核 PR。用户把测试提示词转给家用电脑上的 Agent；本机 Agent 执行后回传报告，云端据此修复并准备下一轮任务。

家用电脑是 AMD Radeon RX 6800，已有 Clef GGUF / llama.cpp Vulkan 服务和历史图形渲染记录。现有材料没有确认相同机器上的 SmolVLA / PyTorch GPU 推理。按具体后端记录能力，不把“有 GPU”推成“所有框架已支持”。

日常直接复用已跑通的环境、服务、缓存和合格报告，只下发当前仍缺的测试。相同代码、输入和参数已有完整报告时直接回传，不重复盘点或部署。实际错误需要诊断时再做针对性检查。当前家用任务是 [CLEF-RECORDED-001](../setup/model_validation/AGENT_TASK.md)。

每次交接包含任务编号、固定 Git 提交、输入/模型身份、执行命令、通过条件和结果格式。回传实际命令、退出码、完整报告与失败日志；GPU 执行还应有实际服务日志或运行时证据。缺少 Git 归档或 shell 历史只表明材料缺失，不能据此断言从未运行过。

CPU 检查、模拟 HTTP 客户端检查、真实模型接口测试、GPU 后端执行、Gazebo 闭环与实物实验分别记录。前一项不能代替后一项。未收到可审阅报告时，将相应结果标记为未确认；不编造成功或否定用户的历史运行记录。

用户手动转交任务和结果即可，不要求云端直接接入 Tailscale。当前不要求家用机安装 ROCm、重装驱动或更换系统，SmolVLA GPU 验证也不强制绑定 RX 6800。证据与决定见 [GPU_EVIDENCE_AND_NEXT_TEST.md](GPU_EVIDENCE_AND_NEXT_TEST.md)。
