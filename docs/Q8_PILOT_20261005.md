# Q8 routing pilot — 2026-10-05

## Hypotheses and scope

The primary M3 hypothesis is a **cost hypothesis**: at comparable independently
measured task success and latency, a calibrated local classifier can reduce paid
slow-model calls. FSM is a required zero-API-cost control. Local inference has
hardware, energy and latency costs; it is not free computation. The historical
16/17 fast selections (about 94%) came from five single-object runs and are not
a general success rate or a demonstrated advantage over FSM.

`FSM_ACTION_AGREEMENT` calibration tests imitation of the deterministic reference.
Its step-level Wilson bounds do not establish episode success, safety or greater
intelligence. Prompt v2 includes the FSM cycle, so agreement cannot serve as an
independent oracle for a claim of superior orchestration.

S7 currently perturbs object placement. Both policies consume actual poses and
the FSM already supports off-canonical placement. S7 alone therefore does not
establish a non-circular differentiation result. A stronger policy claim needs
preregistered cases that require different useful decisions, independent physical
outcome scoring, held-out episodes, and an FSM control. That work is **NOT RUN**.

## Frozen operating points

Retain the existing three bins for this pilot. Use tau = **0.03 and 0.85**:

- Supported middle bin: 1/5 agreement, Wilson lower 0.03622316096978745.
- Supported top bin: 23/23 agreement, Wilson lower 0.8568788745827374.
- Lowest bin: n=2, unsupported even though its numerical bound exceeds 0.03.

The first tau allows middle/top proposals; the second allows only top proposals.
This establishes two possible operating regimes, not a continuous confidence
knob. A lower tau deliberately admits a weak imitation bin and may fail task
smoke. Keep those failures; do not rerun selectively to qualify that arm.

Bin width 0.1 is deferred: the present calibration has only five source episodes
(four calibration episodes and one held-out episode). Smaller bins can become
unsupported and cannot repair circular labels or correlated step observations.

## Entry gates

1. Verify the actual Q8 weight SHA and served GGUF identity; probe TCP, HTTP
   readiness and a real typed inference request.
2. Regenerate calibration whenever the backend source-byte digest changes;
   verify actual loading and record its exact file SHA.
3. Disable host automatic sleep for both power sources. Original settings on
   this desktop were AC 900 seconds / DC 600 seconds; both are now 0.
4. Hybrid runner requires a deployment manifest. Every decision must match its
   runtime fingerprint, tau and loaded calibration SHA. Every invoked Jev
   proposal must have source=jev, no fallback, matching model/weight identity
   and positive measured tokens. A selected fast proposal must additionally
   have a supported calibration bin and the expected calibration SHA.
5. Bootstrap FSM decisions are reported separately. Non-bootstrap FSM fallback,
   mixed profiles or missing usage fail the batch. Sparse-bin escalation may
   pass provenance because it does not authorize a fast route.
6. Each tau requires five same-runtime successful S1 smoke episodes before its
   S1 x20 baseline pilot. Keep smoke and baseline denominators separate.
