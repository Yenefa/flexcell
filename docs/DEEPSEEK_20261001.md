## 官方端点与 5 元预算

官方配置为 `/home/ros/.config/flexcell/deepseek_model.sh`，readiness 成功后也已设为
默认 `mainline_model.sh`；凭据位于独立 mode-600
文件。当前生产端点为 `https://api.deepseek.com/chat/completions`，模型为
`deepseek-flash`。用户授权的 5 元限额写入固定、跨进程持久的预算账本，
不会随重启 fleet 或调用脚本重置。

依据 [官方人民币价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)，
输入未命中缓存的高峰价格为 2 元 / 百万 tokens，输出为 8 元 / 百万 tokens。
账本始终使用这组较高价格、不计缓存优惠；因此展示的是**费用上界，不是账单金额**。
每次发送前按 UTF-8 输入字节上界加 4096 framing tokens、最大 512 输出 tokens，
再乘 2 安全系数预留。预留后累计上界不得超过 5 元；剩余额度不足则不发请求。
收到合法 usage 后结算并释放多余预留；网络结果或 usage 不明保留全部预留。
模型和 endpoint 必须匹配该价格定义，thinking 必须 disabled，不能借该账本
调用另一种更贵模型。没有进行充值或订阅操作。

```bash
export FLEXCELL_MODEL_ENV=/home/ros/.config/flexcell/deepseek_model.sh
source setup/104_mainline_env.sh
bash setup/102_mainline_runtime.sh switch llm 0.7
bash setup/106_single_live.sh /tmp/flexcell_deepseek_single
python3 setup/94_scenario_runner.py --stage smoke --policy llm --batch S1:5
```
