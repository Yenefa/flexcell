# agent 的自述有多准？——LLM 70.3%，确定性检查 100% 但**不能采纳**

## 为什么测这个

上轮确立「只有机制证据可信」。**自述就是机制。**
而 false failure（世界成功、任务报失败）正是恢复重试已完成工作的根源。

现有做法：LLM 自评。这轮拿它跟一个**确定性测量判定**对照，两者都以验收器为准评分。

## 结果

| 方法 | 覆盖 | 正确 | 准确率 |
| --- | --- | --- | --- |
| **LLM 自评** | 64/64 | 45 | **70.3%** |
| **确定性测量判定** | 40/64 | **40** | **100%** |

LLM 的 19 处错误**全部是同一个方向**：世界通过、声称失败。**零次 false success。**

在两者都能回答的 40 例上：

| 指标 | 值 |
| --- | --- |
| 一致 | 21 |
| 不一致 | **19** |
| 不一致的方向 | **全部是 LLM 声称失败而确定性判定为成功** |

## 我本来准备采纳确定性判定——然后发现它有两个盲点

### 盲点一：它验证「执行是否符合计划」，不验证「计划是否符合指令」

如果计划本身指向错的箱子，物体可以**精确落在计划目标上**，
判定说「已达成」、自述为成功，而验收器判失败——**那就是 false success**。

**这批数据里每个计划都是对的，所以这个风险完全不可见。**

### 盲点二（更严重）：容差比余量还大

实测计划目标距区心 **45.0mm**，区半径 **60.0mm** → **余量仅 15.0mm**。
而判定用的容差是 **20.0mm**。

```
箱子可以在计划目标 ±20mm 内 → 距区心最多 65mm
区半径 60mm → 验收器判失败
而判定说「已达成」→ FALSE SUCCESS
```

**即使计划完全正确，这个判定也可能产出 false success。**

152 个阶段目标全部在区内，最紧余量 15.0mm——**小于 20mm 容差**。

## 所以我没有采纳它

| 选项 | 后果 |
| --- | --- |
| 用 LLM 自评（现状） | 19 次 false failure，**0 次 false success** |
| 用确定性判定 | 可能产出 false success |

**使命要求 false success 必须为 0。** 用准确率更高的方法去换一个可能破坏这条红线的方法，
**是错的方向**。准确率不是唯一标准，「错在哪一侧」更重要。

## 要安全采纳它，缺什么

1. 判定必须同时满足「在计划容差内」**和**「所在区半径内」
   （半径对 agent 可见，不算泄漏）；
2. 还必须能发现**计划与指令不符**——否则一条错计划就能骗过它。
3. 第 2 点需要独立的计划复核，本轮未做。

## LLM 那边 19 次错误也值得记一笔

它的错误**全在保守一侧**，与之前的弃权探测一致（做不到时会说）。
这不是「好」，但**方向是对的**：宁可少报成功。
