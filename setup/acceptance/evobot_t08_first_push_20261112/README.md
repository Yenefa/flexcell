## 一个我自己造成的任务设计缺陷

T08 任务：`target_box_a` 起点 x=0.22，`zone_push` 中心 x=0.16、**半径 0.06**。

所以 zone 在 x 上覆盖 **0.10 – 0.22**，而**方块起点正好 0.22，已经在区边界上**。

后果：`inside_zone` 几乎不需要推动就能满足（本次 28.55mm 就进了区）。
**真正的约束来自 30 mm 位移门，不是目标区。**

这削弱了任务「把方块推进区域」的语义。要修的话应该改**任务生成器**（缩小 zone 或把方块起点移出 zone），
**不是改阈值**——阈值是冻结的，降不得。
