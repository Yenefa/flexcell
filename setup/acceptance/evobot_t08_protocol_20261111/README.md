## 为什么这个任务算「新能力」，而不只是新模板

抓放**不能**满足它。判据同时要求：

| 要求 | 抓放会怎样 | 什么都不做会怎样 |
| --- | --- | --- |
| 水平位移在 [30, 150] mm | 可能满足 | **不满足** |
| 垂直位移 ≤ 20 mm | **不满足**（抬起就是搬） | 满足 |
| 方向余弦 ≥ 0.9 | 视情况 | 未定义（位移太小） |

**两个半边必须同时成立**，所以「抓起走过去放下」失败、"不动"也失败。
缺的能力是**持续接触推动**——现有 `RunComposite` 只能表达 pick-and-place。
