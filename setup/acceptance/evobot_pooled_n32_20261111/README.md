## 为什么扩到 32

上一轮的「4/16 = 25% stall」「3/4 = 75% 恢复」都是**点估计**。
n=16 时 25% 的 95% 区间大约 **10%–49%**——宽到不能支撑任何结论。

本轮用**全新种子**（T13 7300–7307、T12 7400–7407）再跑 16 例，
封存独立，不复用任何实例。
