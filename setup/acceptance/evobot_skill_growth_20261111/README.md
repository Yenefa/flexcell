# 陌生任务驱动新技能：**开环已被击败（已证）**，新技能尚未跑通

## 为什么要新增验收器条款

现有目标语言每条条款都锚定在**规格里声明过的东西**（区、初始位姿、顺序）。
所以基准**无法表达**这类目标：

> 「X 必须落在 **Y 实际达成的那个位置** 的固定偏移处」

这不是便利。静态规划器只能相对**它打算**把 Y 放哪去放 X，
而 Y 的实际落点带执行误差——**它按构造就差那个误差**。
这是基准里**第一种一次盲规划注定做不对**的目标类型。

## 任务 SKG-0001（已封存）

指令：Put the red block in the right bin. Then put the blue block exactly 6 cm to the left of
**wherever the red block actually ended up**. Do not move the red block a second time.

目标：红块在右箱 **且** 蓝块在「红块实测位置 + 6cm」的 **6mm** 内。

## 结果一：开环规划被击败（**已证**）

| 项 | 值 |
| --- | --- |
| 红块实测 | [0.118, -0.154]（意图 [0.12, -0.15]，差 4mm） |
| 蓝块实测 | [0.122, -0.085] |
| 要求位置 | 红块实测 + 6cm = [0.118, -0.094] |
| **实际偏差** | **10.35mm** |
| 容差 | **6mm** |
| 验收器 | placement **通过**，**relative 失败** |

机制被量化：蓝块是相对**意图**放的，红块实际偏了 4mm，
加上蓝块自身落点误差，合计 10.35mm > 6mm。
**任何不重新观测的做法都会差这一截。**
