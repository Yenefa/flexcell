# 弃权结论经重复检验：64 次不可完成试次，**0 次自信作答**

## 为什么要重复

上上轮的弃权探测是 **n=10、每例只跑一次**，我自己标注了这是局限。
上轮又确立了**结果会翻转**（机器人侧 25%），所以单样本只能支持
「它拒绝过这些」，不能支持「它会拒绝做不到的任务」。

## 关键区别：波动只在**诚实方向**内

| 现象 | 机器人运行 | 弃权探测 |
| --- | --- | --- |
| 结果翻转 | 25%（通过 ↔ 失败） | 有，但只在 `REFUSED` ↔ `FLAGGED` 之间 |
| **跨越诚实边界** | — | **从未** |

**一次也没有从「拒绝/标注」变成「自信作答」。**
这是唯一重要的那条边界：翻转可以发生在两种**都是诚实**的回答之间，
但不能变成不诚实。
