# 修正上轮的过度概括：基准**能**区分，但只在**跨类型**时

## 上轮我说了什么

> 确定性解析器 64/64，LLM 64/64 → **「这个基准无法展示 LLM 是必要的」**

**这句话太强了。** 那个解析器是**看过全部三个模板之后**写的，
它只测到了「**已见类型内部**」的饱和。

## 更锋利的实验

把这个规则器**去掉 T14 分支**（等价于「只针对 T12/T13 写的规则」），
再拿去解 T14 的 16 例。

## 结果

| 基线的知识范围 | T14 得分 |
| --- | --- |
| **规则（无 T14 分支）** | **5/16** |
| 规则（含 T14 分支） | 16/16 |
| **LLM** | **16/16** |

## 但这 5 分是运气，不是理解

逐例核对：

| 情形 | 数量 | 说明 |
| --- | --- | --- |
| 要求顺序 = `[a,b]` | **5** | 恰好等于物体枚举顺序 → **规则器天然排对** |
| 要求顺序 = `[b,a]` | **11** | 规则器**全部忽略顺序**，输出 `[a,b]` |

**规则器对新约束的理解是 0/16。** 它的 5 分完全来自「顺序恰好撞上」。

## 这也暴露规则器的一个校准缺陷

在那 11 例里，规则器**没有拒绝**——它产出了一个违反约束、但看起来正常的计划。

而 LLM 在同类情形下会标注不确定（上一轮弃权探测：8 个不可能指令 0 例自信误答）。

**「沉默地做错」与「承认不确定」是两种不同的失败。**

## 修正后的结论

| 范围 | 结论 |
| --- | --- |
| **同一模板族内部** | 规则 == LLM（63/64 一致），**基准在此饱和** |
| **跨模板族** | 规则理解 **0/16**，LLM **16/16** → **真实增量** |

所以「基准无法展示 LLM 必要」**只在族内成立**。跨族时它能区分，而且是大幅区分。

## 对梯子的影响

Level 8 上轮被我直接降级，**现在应该写成有条件的**：

```
跨类型泛化：成立（规则 0/16 vs LLM 16/16）
族内泛化  ：不成立（规则同样 64/64）→ 不能作为推理证据
```

## 不宣称

- 不宣称 LLM「可靠」——只宣称它在**这一个新类型**上比无对应规则的规则器强；
- 不宣称规则永远不能扩展到 T14（我随时可以补一条规则，那就回到族内饱和）；
- 不宣称 0/16 的「理解」是严格证明（30 例样本；顺序=枚举顺序时无法区分）；
- **未上真机，M0**。

## 这轮的教训

我上轮用一个**看过全部模板的解析器**去论证「解析器也够」，
**这个论证在方法上就是错的**——它不能区分「基准简单」与「解析器已知答案形状」。
去掉相应分支才是正确的对照。
