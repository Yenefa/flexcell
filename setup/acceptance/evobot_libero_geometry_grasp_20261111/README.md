# 从几何推导抓取：迁移 1/3 → **2/5**，剩余失败有两种不同机制

## 上轮的结论驱动了这轮

上轮迁移 1/3，两次失败都是抓取，原因是**下探偏移是手工调的常数**（物体中心 +2cm）。
所以这轮改成：**测量目标物体的几何范围，据此选择抓取高度**——数字来自物体，不来自我。

## 结果

| index | 物体 | 几何范围 z | 抓取 z | 官方成功 |
| --- | --- | --- | --- | --- |
| 0 | alphabet_soup | -0.051 … 0.081 | 0.015 | **True** |
| 1 | cream_cheese | -0.048 … 0.048 | -0.000 | **True** |
| 2 | salad_dressing | -0.069 … 0.117 | 0.024 | False |
| 3 | bbq_sauce | -0.046 … 0.099 | 0.027 | False |
| 4 | ketchup | -0.069 … 0.118 | 0.024 | False |

**2/5**（上轮同批前三个是 1/3）。抓取高度换成几何推导，**确实修好了 cream_cheese**。

### 高度不是万能钥匙：试了更高的抓取比例

| 抓取位置 | 结果 |
| --- | --- |
| 中点（0.5） | 2/5 |
| 0.85（近顶部） | 2/5 |
| 0.70 | 2/5 |

**三个比例结果完全相同** → 说明剩下三个失败**不是高度问题**。

## 三个失败是两种不同的机制

| 任务 | 日志事实 | 机制 |
| --- | --- | --- |
| salad_dressing | 目标 eef z=0.024，**实际只降到 0.107**；物体仅位移 3.8cm 后停住 | **降不下去**——手指被瓶口挡住，从未真正夹住 |
| ketchup | 同上（瓶形相同） | 同上 |
| bbq_sauce | **搬起来了**（z 0.189），最终落在 `[-0.014, 0.232]`，距目标区域轴 3.6cm | **释放点偏了 3.6cm**，落在篮外 |

**这是两种不同的修复**：高瓶需要**侧向抓取**（而不是从正上方下探），
而搬运成功的那一个不是抓取问题，是**释放精度**问题。
