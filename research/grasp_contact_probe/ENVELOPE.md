# 不用磁吸，现在能做到什么程度（全流程实测）

被测动作：**抓 → 抬 0.15 m → 搬 0.25 m → 降 0.15 m → 松 → 落位**，
一次 trial 3.1 s 仿真、逐 1 ms 记录。物体是任务同款 **35 mm / 50 g** 箱，μ = 1.0。
判据：抓起 ≥0.10 m、搬运全程相对漂移 < 2 mm、搬出 ≥0.20 m、释放后指垫脱离且落地、落点误差 < 20 mm。

原始数据：`results/transport-v1/`（20 N 饱和夹持，24 trial）、`results/realistic-v1/`（软夹持，18 trial）、
`results/gripforce-v1/`（夹持力 × 载荷网格，15 trial）。逐 trial 表在各目录的 `ENVELOPE.md`。

## 1. 饱和夹持（闭合指令 0.020 m，指力上限 20 N）——当前主线最可能的用法

| 条件 | 结果 |
| --- | --- |
| 无误差 | PASS，漂移 0.001 mm，落点误差 0.00 mm |
| 横向误差 2/4/6/8/10/12/15/20/25 mm | **9/9 PASS**，漂移 ≤1.13 mm，落点误差 = 抓取偏移本身 |
| yaw 5/10/15/20/30/45/60° | **7/7 PASS**，漂移 0.001 mm |
| 搬运用时 0.35 s / 0.25 s（≈12→19 m/s²，1.2–2 g） | **3/3 PASS** |
| 合计 | **24/24 PASS** |

## 2. 夹持力 × 载荷（决定“能搬多重”的唯一参数）

搬运为 0.25 m / 0.6 s（峰值加速度 3.6 m/s²），饱和闭合：

| 指力上限 | 50 g | 200 g | 500 g |
| --- | --- | --- | --- |
| 2 N | PASS | PASS | **FAIL**（掉） |
| 3 N | PASS | PASS | **FAIL**（滑 11.9 mm） |
| 5 N | PASS | PASS | PASS |
| 8 N | PASS | PASS | PASS |
| 20 N | PASS | PASS | PASS |

先看清“指力上限”与“实际法向力”不是一回事：实际法向力 `N = min(kp × 干涉量, cap)`。
本 rig 干涉量 7.5 mm × kp 1000 = **7.5 N**，所以 cap ≥ 8 N 时法向力恒为 7.5 N，8 N 与 20 N 两行完全相同；
cap 削到 2 / 3 / 5 N 时，上限相应落到 ≈0.30 / 0.45 / 0.75 kg（`m_max = 2μN/(g+a)`）。
**任务只需要 50 g**：即使只给 2 N 也有 6 倍余量，远低于 OMX 的 10–20 N 夹持力。

## 3. 软夹持（闭合指令 0.033 m，即只压 2 mm；等效约 1 N）

这是“很客气地夹一下”的情形，用来测下限：

| 条件 | 结果 |
| --- | --- |
| 无误差 / x 6 mm / y ≤10 mm（6 项）/ yaw 15–60°（4 项）/ 搬运 0.25 s 与 0.15 s | **13/18 PASS**（漂移 ≤0.98 mm） |
| y = 12 mm | **FAIL**（滑 15.2 mm，落点偏 14 mm） |
| y ≥ 15 mm | **FAIL**（指垫完全错过物体，抓空） |
| 200 g / 500 g | **FAIL**（容量 2 N < 需求） |

**这一组给出了真正的几何边界：横向容差 ≈ 10 mm（物体半宽 17.5 mm + 指垫半开 28 mm → 越过 10.5 mm 就有一侧指垫错过物面）。**

## 4. 结论：现在不用磁吸能做到的程度

1. **任务同款 35 mm / 50 g 箱，全流程 100% 通过**（抓-抬-搬-降-松-落位），漂移 < 1.2 mm，落点误差 = 抓取偏移（不累积）。
2. **抓取位姿误差容限**：横向 ≤10 mm 稳过（饱和夹持下到 25 mm 仍过，但那时靠 4–7 mm 的求解器穿透“兜住”，不可信）；yaw ≤60° 无影响；沿指方向 ≤12 mm（只影响落点精度）。
3. **搬运刚度**：0.25 m / 0.6 s 常规，压到 0.15 s（≈7 g 加速度）仍不掉，漂移 0.98 mm。
4. **载荷上限由夹持力唯一决定**：5 N → 500 g，20 N → 1.1 kg；任务只要 50 g。
5. **失效模式是可预测的两类**：抓空（偏移超过指垫覆盖，>10.5 mm）与滑移（载荷超过 2μN）。没有出现第三种意外。

## 5. 这些数字不能覆盖什么

- **穿透换来的通过**：饱和夹持（gap 0.02 对 35 mm 物体 = 每侧 7.5 mm 干涉）时，大偏移 trial 的“通过”靠求解器允许 4–7 mm 穿透把物体兜住；真机不会有这个自由度，所以 **§1 的 24/24 是乐观上界，§3 的软夹持表才是保守下界**。
- **位姿误差只当平移/旋转注入**，没有视觉噪声、没有标定偏差、没有物体在桌面上的初始扰动。
- 单一 DART 6.13.2 + 1 ms 步长；接触刚度与步长耦合，换步长要重测。
- 物体是规整立方体，没有曲面、没有柔性、没有重心偏心。
